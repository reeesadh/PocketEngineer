PocketEngineer is an openclaw powered study app for students to learn and practice physics content of their choice

To use the app:
1. run an openclaw agent locally on your machine
2. ensure you have node.js and npm installed
3. clone this repository
4. in the cloned repository, within renderer.js, search for "TODO" and update the openclaw gateway token with your own
5. navigate to the repository from terminal and run "npm start" to launch (note: you may have to force install electron first)
